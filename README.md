# Form Fitness

Form Fitness is a five-page fitness website about exercise, nutrition, and healthy daily habits.

## Features

- An interactive anatomy explorer that links arms, abs, and legs to their exercise sections.
- Exercise instructions for each muscle group, with extra steps users can expand.
- A personal nutrition form for entering basic details and diet goals.
- A weekly workout schedule and sample two-day meal plans with calorie and macronutrient information.
- A handbook with general calorie guidance and food-label tips.

The nutrition form collects information but does not automatically generate a meal plan yet. The meal plans are general examples, and individual calorie needs vary.

## Built with

HTML, CSS, and Bootstrap.

Open `index.html` in a web browser to view the site. Bootstrap is loaded from a CDN, so an internet connection is needed for Bootstrap styling.
